# Furqan Ali Portfolio

A creative React + Tailwind CSS portfolio website for **Furqan Ali**, designed around the colors `#379392` and `#3F4045`.

## Run the website

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal, usually:

```bash
http://localhost:5173
```

## Build for production

```bash
npm run build
```

## Edit important content

Most website content is inside:

```bash
src/App.jsx
```

Design and custom CSS are inside:

```bash
src/styles.css
```
